### [Text-to-Handwriting Synthesis with ACGANs](https://github.com/sp2772/Text-to-Handwritten-Document-using-ACGANs)

End-to-end handwriting synthesis pipeline using **Auxiliary Classifier GANs** trained on 398K NIST images across 47 character classes. Includes an intelligent document image generator that converts arbitrary text into realistic handwritten documents with proper formatting.

`DCGAN` `TensorFlow` `Keras` `Data Pipeline` `Generative AI`

### [Fabric Defect Detection - Edge-Optimized](https://github.com/sp2772/fabric-defect-detection)

Implementation of **FN-Net**, a lightweight CNN for fabric defect detection on edge devices. Applied adaptive thresholding, **Quantization Aware Training (QAT)**, and post-training quantization to achieve an optimal performance-to-size ratio with significantly reduced memory footprint.

`Edge AI` `Model Compression` `Quantization` `CNNs` `Computer Vision`
