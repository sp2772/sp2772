## Featured Projects


---
###  [Agentic Character Chatbot with Personality Simulation](https://huggingface.co/spaces/sp2772/Vivianbysp27)
> *Deployed on Hugging Face Spaces*

Conversational AI system that replicates complex character personalities with contextual awareness. Built with a **multi-agent LangChain architecture**: a personality controller agent, an emotion tracking module, and a response generation module. Supports dynamic persona injection through structured prompts without retraining.

`LangChain` `Multi-Agent` `LLMs` `Prompt Engineering` `HuggingFace`

---

###  [Text-to-Handwriting Synthesis with ACGANs](https://github.com/sp2772/Text-to-Handwritten-Document-using-ACGANs)

End-to-end handwriting synthesis pipeline using **Auxiliary Classifier GANs** trained on 398K NIST images across 47 character classes. Includes an intelligent document image generator that converts arbitrary text into realistic handwritten documents with proper formatting.

`GANs` `ACGANs` `Computer Vision` `Generative Models` 

---

###  [Generative Character Art Pipeline](https://github.com/sp2772/Generative_Character-An_Artistic_Interpretation)

Built an end-to-end pipeline to generate novel character art using a **DCGAN from scratch**. Includes a custom data collection module (pixivpy scraping), automated tag filtering, and a pre-trained **YOLOv3 anime face detector** for dataset preprocessing.

`DCGAN` `TensorFlow` `Keras` `Data Pipeline` `Generative AI`

---

###  [Fabric Defect Detection - Edge-Optimized](https://github.com/sp2772/fabric-defect-detection)

Team implementation of **FN-Net**, a lightweight CNN for fabric defect detection on edge devices. Applied adaptive thresholding, **Quantization Aware Training**, and post-quantization to achieve a better performance-to-size ratio than baseline models with significantly lower memory footprint.

`Edge AI` `Model Compression` `Quantization` `CNNs` `Computer Vision`

---

###  [AI Scribble Recognition System](https://github.com/sp2772/ai-finds-what-you-scribbled)

Real-time hand-drawn sketch recognition across **345 categories** using a custom CNN on Google's QuickDraw dataset. Features progressive partitioning for incremental training and parallel data downloading. Deployed as an interactive Django web app and a Tkinter GUI.

`CNN` `Django` `Real-Time` `Sketch Recognition` `QuickDraw`

---

### [SALVO — AI Club Platform](https://github.com/SALVO-AI-ML-Club-of-SASTRA/SALVO-Website)

As a team of 3, deployed a Full-stack Django platform for SASTRA's AI/ML club, for University students. Features role-based access for club management, a community ML model/dataset repository, AI-powered blog with automated content moderation, and a live **Scribble game** where multiple DL models compete to guess user-drawn sketches in real time.

`Django` `Full-Stack` `Multi-Model` `Community Platform`
